# 아틀라스

**브라우저 속 대학.** 설치도 가입도 없이, 그림을 직접 움직이며 대학 전공 과정을 혼자 따라가는 인터랙티브 교과서입니다.

**사이트:** https://ksiksit.github.io/ai-atlas/

## 무엇인가

아틀라스는 대학처럼 짜여 있습니다. 첫 화면에서 전공을 고르면 그 전공의 **이수체계도**가 열립니다. 이수체계도에는 전공기초, 전공필수, 전공선택으로 나뉜 과목이 100·200·300번대 순서로 놓이고, 선수과목은 화살표로 이어집니다. 과목은 파트와 장으로 나뉘며, 장마다 글 옆에 직접 조작하는 그림이 있습니다.

교과서 한 권을 고르는 대신 **무엇을 어떤 순서로 공부할지**부터 보여 주는 것이 아틀라스의 출발점입니다. 한 과목을 여러 전공이 함께 쓰기 때문에, 예를 들어 선형대수는 수학 전공의 필수이면서 인공지능 전공과 컴퓨터과학 전공의 기초가 됩니다.

## 누구를 위한가

대학 전공 과정을 **혼자** 따라가고 싶은 사람을 위해 만듭니다.

- 학교 밖에서 컴퓨터과학이나 수학을 처음부터 체계적으로 공부하려는 학생
- 일하면서 놓친 기초(수학, 컴퓨터 구조, 운영체제, 네트워크)를 다시 다지려는 개발자
- 다른 분야로 옮기려고 그 분야의 전공 과정이 어떻게 생겼는지 보고 싶은 사람

## 원칙

1. **읽기보다 만져 보기.** 장마다 핵심 개념을 손으로 바꿔 볼 수 있는 그림이 있습니다. 슬라이더를 끌고, 코드를 고쳐 돌리고, 시뮬레이션을 한 단계씩 멈춰 들여다봅니다.
2. **그 자리에서 진짜로 계산한다.** 그림은 미리 그려 둔 애니메이션이 아닙니다. 신경망은 브라우저 안에서 실제로 학습하고, 데이터베이스 장의 쿼리는 작은 쿼리 엔진이, 그래픽스 장의 장면은 픽셀을 하나씩 칠하는 렌더러가, CPU 장의 프로그램은 어셈블러가 딸린 가상 CPU가 돌립니다.
3. **같은 설정이면 같은 결과.** 확률, 강화학습, 분산 시뮬레이션처럼 무작위가 들어가는 실험은 씨앗이 정해진 난수를 씁니다. 다시 해도 같은 결과가 나오고, "다시 굴리기"로 바꿔 볼 수 있습니다.
4. **아무것도 보내지 않는다.** 백엔드가 없습니다. 계정도, 읽은 장 기록도 없고, 반응 시간처럼 독자의 브라우저에서 잰 값도 그 페이지 안에서만 씁니다. 이 브라우저에 저장하는 것은 화면 테마 선택 하나뿐입니다.
5. **어디서나 열린다.** 정적 사이트라 어느 호스팅에나 올릴 수 있고, 파일 하나로 된 버전은 더블클릭으로 열 수 있습니다.

## 전공

| 전공 | 무엇을 배우나 | 주소 |
| --- | --- | --- |
| 인공지능 전공 | 컴퓨터가 스스로 배우는 원리에서 대형 언어 모델까지 | `#majors/ai` |
| 컴퓨터과학 전공 | 프로그래밍과 증명에서 CPU, 운영체제, 계산의 한계까지 | `#majors/cs` |
| 네트워크·보안 전공 | 데이터가 오가는 길과 그 길을 지키는 법 | `#majors/net` |
| 소프트웨어공학 전공 | 내 컴퓨터의 코드에서 사람들이 쓰는 서비스까지 | `#majors/se` |
| 수학 전공 | 증명과 미적분에서 해석학과 대수까지 | `#majors/math` |

통계학은 전공을 따로 두지 않고 다른 전공의 기초나 선택 과목으로 씁니다. 2026년 11월 기준으로 34개 과목, 216개 장이 있습니다. 전공별 과목 구성과 과목별 장 목록은 [커리큘럼](docs/curriculum.md)에 있습니다.

## 이름에 대해

아틀라스는 지식의 지도라는 뜻입니다. 처음에는 인공지능 하나만 다루는 사이트로 시작해서 저장소 이름이 `ai-atlas`로 남아 있습니다. 지금 인공지능은 여러 전공 가운데 하나입니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
```

## 빌드

```bash
npm run build           # dist/ — 일반 정적 사이트 (어느 정적 호스팅에나 업로드 가능)
npm run build:single    # dist-single/index.html — 파일 하나로 된 버전 (더블클릭으로 열 수 있음)
```

## 배포

`main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/deploy.yml`)가 빌드해서 GitHub Pages에 자동으로 배포합니다.
